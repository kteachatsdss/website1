Unit 6-Electronics

Unit description

This unit focuses on electronics, specifically on how arduinos are used to create electronic circuits. Using C++ and online circuit websites such as Tinkercad, we are able to create electronic circuits that can be created in real life using physical parts. Components such as resistors, buzzers, and LEDs are all creatively used by the students to create this circuits.
